# Naja Safety Image Map

Drop your final, Lightroom-exported image into each folder. One image per folder (or a `hero.jpg` + `thumb.jpg` pair if you want variants).

**Naming convention inside folders:**
- `hero.jpg` — the main full-width hero/banner version
- `thumb.jpg` — cropped card/thumbnail version (if needed)
- `raw.jpg` — unedited original (optional backup)

**Export settings for web:**
- **Hero banners:** 1920×1080 px, 80% quality JPEG, sRGB
- **Card thumbnails:** 800×600 px, 80% quality JPEG, sRGB
- **Portraits:** 1200×1600 px (portrait), 80% quality JPEG, sRGB

## Lightroom Quick Tips

1. **Hero banners:** Crush the blacks slightly, add a subtle vignette, and make sure the left third is dark enough for white text overlay.
2. **Cards:** Punch up clarity (+10 to +20) — small images need extra definition.
3. **People:** Warmth +5 to +10 for skin tones. Avoid oversaturating safety vests (easy to blow out the orange).
4. **Consistency:** If you find 2–3 photos with similar lighting/editing, prioritize those. The site will look more cohesive.
